# 共用本地用户

在 macOS 上，已接入的游戏使用同一份本地用户列表。目前包括《朋友收集：梦想生活》、王国之泪、旷野之息、
《咚奇刚 蕉力全开》和《宝可梦 Pokopia》的原生运行时构建。采用独立运行时的其他游戏尚未接入；《集合啦！
动物森友会》有自己的存档行为，不属于这份用户列表。

## 用户与存档

- 共用列表保存在 `~/Library/Application Support/MacNativeGames/Accounts/users.plist`。
- 最多有 **8 个启用用户**。初始用户叫 **Local**，不能移除。
- 新增用户在已接入的游戏间共用相同的 ID 和名称。**Local** 保留各游戏已有的身份，因此旧存档仍能打开；
  Local 的 ID 可能因游戏而异。
- 存档仍按游戏和用户分别保存。每个游戏保留自己的 profile 和存档；共用用户不会让不同游戏共用岛屿或存档。

## 选择和管理用户

- 只有一个启用用户时，游戏直接启动；有多个用户时，启动前选择本次使用的用户。塞尔达构建会预选 profile
  中保存的用户；《朋友收集：梦想生活》目前默认预选 **Local**。
- 设置面板显示本次运行使用的用户，并提供共用用户管理入口。游戏运行期间保持该用户；选择其他用户后，
  会在之后启动游戏时生效。
- 可以在管理器中添加、移除和恢复用户。移除会把用户归档，不会删除该用户的游戏存档，之后也可以恢复。
  默认 Local 用户不能移除。

## 旧数据和平台范围

- 共用列表首次读取时，会从已有塞尔达 `users.txt` 导入其他用户。原有游戏 profile 和存档保留；塞尔达仍会
  维护各自的 `users.txt`，供存档工具兼容使用。
- 归档用户不会导致其游戏存档被删除。
- 共用选择器和管理器目前仅支持 macOS；iOS 独立账号路径保持原样。

`games/common/tests/test_users.py` 覆盖共用列表及各游戏存档映射；《朋友收集：梦想生活》的设置测试会检查面板
是否显示当前用户。
